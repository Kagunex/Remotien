# Visual Art Direction

## Gaya Utama
- **3D Playful Educational Motion Design**: Material *glossy plastic/clay*, bentuk geometris membulat, pencahayaan studio lembut.
- **Pencahayaan**: Key light dari atas kiri (`[-6, 9, 7]`), bayangan halus pada lantai studio lavender (`#9B83D1`).
- **Gerakan Kamera**: Menggunakan kurva *cubic easing* dan *spring* deterministik (`useCurrentFrame()`), maksimal 2–3 objek utama per shot.

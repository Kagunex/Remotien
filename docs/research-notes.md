# Research Notes — Bagaimana Internet Bekerja?

## Konsep Inti Edukasi
1. **Internet sebagai Network of Networks**: Infrastruktur global yang menghubungkan miliaran perangkat melalui kabel serat optik bawah laut, menara seluler, dan satelit.
2. **DNS (Domain Name System)**: Menerjemahkan nama domain ramah manusia (`example.com`) menjadi alamat IP numerik server tujuan (`93.184.216.34`).
3. **Packet Switching**: Data dipecah menjadi unit-unit kecil (paket) dengan header alamat asal/tujuan serta nomor urut agar efisien dan tahan gangguan.
4. **Dynamic Routing**: Router membaca header tujuan dan meneruskan paket lompatan demi lompatan (hop-by-hop) melalui jalur paling optimal saat itu.
5. **Client-Server Request/Response**: Server menerima permintaan, memproses logika/basis data, dan mengirimkan respons kembali ke perangkat klien untuk dirakit ulang oleh browser.
